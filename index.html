🎛️ Types of Control Actions

TypeBehaviourUse When
ON/OFF Fully ON or OFF only. Add hysteresis to stop chattering (rapid switching). Precise control NOT needed
P Output proportional to error. May have steady-state offset. Moderate precision
PI P + eliminates steady-state offset (integral accumulates error). No offset needed
PID PI + reduces overshoot via derivative. Fastest settling time. Most precise. Best precision
Motion Tracks a moving setpoint. Shaft encoder feedback + PWM for speed control. Robots, CNC machines
💡 Hysteresis = a dead band around setpoint. Prevents ON/OFF from switching too rapidly. Used only when precise control is NOT needed.

⚔️ PLC vs DCS

PLC

  • Factory / discrete automation
  • Replaced relay control panels
  • Modular, expandable rack
  • Ladder Logic programming
  • Cars, conveyors, robots

DCS

  • Process / continuous industries
  • Tight HMI integration
  • Engineering workstation config
  • Complex loop control
  • Oil refineries, water treatment

Introduction to PLC

Definition · History · 5 Components · Scan Cycle · Languages

💡 PLC Definition

A digital electronic device that uses a programmable memory to store instructions for logic, sequence, timing, counting, and arithmetic — to control machines and processes.
Also: continuously monitors input devices and makes decisions based on a custom program to control output devices.
📅 First PLC: MODICON 084 (1969)  ·  Built to survive heat, dust, moisture, vibration

🔩 5 Main Components of a PLC

1
CPUExecutes user program. Contains ALU + internal timers/counters/flags.
2
MemoryData Table + User Program + Housekeeping (3 sections).
3
I/O InterfacesDiscrete (ON/OFF) or Analogue (4–20mA / 0–10V). Opto-isolated.
4
Power SupplyConverts 120/240V AC → DC for all modules.
5
ProgrammerPC or handheld device to enter the program into memory.

🔄 PLC Scan Cycle — Repeats Forever

⚠️ Scan Time = time for one full cycle. If an input changes TWICE in one scan, the PLC may never detect it!

PLC Programming

5-Step Design · I/O Addressing · Ladder Rules · Latching · Interlocking

📋 5-Step Design Process

  1. 1
    Determine Sequence of Operation — Draw a flowchart of what the machine does
  2. 2
    Assign I/O Addresses — Label every sensor/actuator with an I or Q address. Do this BEFORE writing the program.
  3. 3
    Write the Ladder Program — Follow the control sequence from Step 1
  4. 4
    Download to PLC — Check coding errors, simulate if possible
  5. 5
    Run & Test — Verify wiring, debug, test thoroughly before handing over

📊 Ladder Logic — Key Rules & Symbols

─┤ ├─ NO Contact (XIC)

Normally Open. Closes when bit = 1. "Examine If Closed."

─┤/├─ NC Contact (XIO)

Normally Closed. Opens when bit = 1. "Examine If Open."

─( )─ Output Coil

Energised when any left-to-right path is TRUE. ONE per rung.

✓ Series contacts = AND logic
✓ Parallel contacts = OR logic
✓ Input contacts can appear multiple times
✓ Current flows left → right, top → bottom
✗ Output coils CANNOT be in series
✗ Each output address can only appear ONCE

🔒 Latching vs Interlocking

Latching

Locks output ON even after input goes false.

Only released when UNLATCH coil is energised.

eg: motor start/stop seal-in circuit

Interlocking

NC contact of Output A placed in rung of Output B (and vice versa).

Prevents two conflicting outputs from being ON simultaneously.

eg: motor FWD and REV cannot both be ON

🧠 Memory trick:  TON = "Turn ON late"  |  TOF = "Turn OFF late"

🗂️ S7 Timer Types (64 total: T0–T63)

S_Pulse Pulse — active for fixed duration, ignores input length
S_Pext Extended Pulse — restarts if retriggered before expiry
S_ODT ON Delay Timer (TON) ★ most used
S_ODTS Retentive ON Delay — keeps accumulated time even if input drops
S_OFFDT OFF Delay Timer (TOF) ★ most used
🔧 Timer rule: Timer instruction must be placed next to the RIGHT RAIL of a rung.

🔢 Counters (S7: 64 total, C0–C63, range 0–999)

CU Count Up

+1 on each rising edge. Stops at 999.

CD Count Down

−1 on each rising edge. Stops at 0.

CU+CD Up / Down

Dir=0 → count up. Dir=1 → count down.

Counter Pin Connections
CU Count Up input CD Count Down input S Set — loads preset value R Reset → count = 0 PV Preset Value (C#0–999) Q Output: 1 if count > 0 BI Current value (binary) BCD Current value (BCD)

📖 Key Definitions Cheatsheet

PLC Digital computer for industrial process control using programmable memory
Scan Time Time for one complete Read Inputs → Execute Program → Update Outputs cycle
TON ON-Delay Timer — output turns ON after a set delay following input activation
TOF OFF-Delay Timer — output turns OFF after a set delay following input deactivation
Latch Lock output ON indefinitely — only released by explicit UNLATCH coil
Interlock NC contact of Output A in rung of B — prevents conflicting simultaneous outputs
XIC Examine If Closed — the NO contact instruction (bit must be 1)
XIO Examine If Open — the NC contact instruction (bit must be 0)
RLO Result of Logic Operation — logical result evaluated in a rung
Hysteresis Dead band added to ON/OFF control to prevent rapid chattering
HMI Human Machine Interface — operator display for process monitoring
PIQ Process Output Image — PLC's internal memory table of all output states
